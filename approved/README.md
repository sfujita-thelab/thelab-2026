# thelab 2026

## Overview

A redesign of thelab.co, built as a working prototype for alignment and dev scoping.
Not production code.

## Scope

- **Homepage:** hero, Featured Work, Expertise, Proof, footer
- **Expertise:** the four areas, their case studies, the FAQ
- **Work:** the case-study grid with industry filters

All pages share one token file and one footer. Details are in `HANDOFF.md`.
